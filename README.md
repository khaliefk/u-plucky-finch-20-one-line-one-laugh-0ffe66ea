A make.fun bounty entry: one funny line, 200 characters or fewer, judged
head-to-head by an AI comedy editor.

## The entry

> My GPS took me past my ex's house and whispered, 'Closure is only 400 metres away.'

## How it works

`main.py` writes that single line to `/output/entry.txt` (83 characters,
one line, UTF-8, no trailing newline). Standard library only.

Run it:

```sh
python3 main.py
```
